# 미팅 반영 사항: 논문별 정보와 Future Work

## 요구 의미

최종 Markdown 보고서는 각 논문의 내용, 한계, Future Work, 공통 참고문헌을 식별할 수 있어야 한다. 미팅의 Future Work는 논문 저자가 원문에서 제시한 향후 연구를 뜻한다. 여러 논문의 비교로 도출하는 Research Gaps와 별개로 취급한다. 원문에 해당 내용이 없으면 미기재/근거 없음으로 표시하며, 시스템이 만든 제안을 저자의 제안으로 표시하지 않는다.

공통 참고문헌은 기존 정의대로 선정 논문 중 두 편 이상이 인용한 문헌이다. Agent 2가 공통 문헌과 인용한 선정 논문 ID를 산출하고, Agent 4가 이를 논문별 목록과 전체 목록으로 보여준다. 각 논문의 전체 참고문헌을 모두 공통 문헌으로 간주하지 않는다.

## 현재 구현과 차이

| 항목 | 현재 | 보완 예정 |
|---|---|---|
| 논문 내용 | 논문별 요약, 방법/데이터/결과 비교표 | 논문별 항목 배치를 팀과 합의 |
| 한계 | ReaderResult.limitations 및 별도 보고서 섹션 | 논문별 한계 구분 강화 |
| Future Work | 전용 논문별 필드 없음. research_gaps는 보고서 전체 단위 | Reader의 논문별 future_work 근거 필드와 Writer 반영 필요 |
| 공통 참고문헌 | Agent 2의 문헌별 인용 논문 ID 및 전체 보고서 표 | 논문별 공통 문헌 목록 추가 |

이 문서는 요구사항 정리이며 위 보완 구현을 완료했다는 의미가 아니다. 이번 GitHub 공유는 기존 Agent 1/2/4 개발분의 공유다.

## 팀 경계

- 그룹 2 Reader: 논문 내용·한계·저자의 Future Work와 원문 근거를 구조화하여 전달하는 인터페이스를 협의한다.
- 그룹 3 Agent 2: 공통 문헌 식별, 서로 다른 인용 논문 수 집계, 불확실성 표시.
- 그룹 3 Agent 4: 위 입력의 근거를 유지하며 논문별·종합 Markdown을 작성.
- 그룹 1 Supervisor: Coverage/Evidence 최종 판정. 현재 그룹 3의 모델 검토는 이를 대체하지 않는다.

future_work의 정확한 스키마와 보고서 목차는 아직 팀 공통 계약으로 최종 확정하지 않았다. 기존 v0.1 어댑터 경계에서 교체 가능하게 확장한다.
