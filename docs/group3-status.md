# Agent 1·2·4 검증 상태

## 이번 범위 정리

공유 대상은 Agent 1 Retrieval, Agent 2 Common References, Agent 4 Writer 및 실행에 필요한 공통 스키마·설정·CLI·테스트·예시다. 담당 에이전트의 입출력 계약과 시험 입력은 필요하므로 포함한다.

이전에 올린 A2A 서버, 타 그룹 서비스 연동·공유 저장소 전달 도구, 해당 보조 테스트·문서·실행 스크립트와 서버 의존성은 이번 담당 개발분에서 제외한다. 이 제외는 에이전트의 생성·검토·검색 정책을 바꾸는 작업이 아니다.

## 실제 실행과 Mock 구분

이전 실제 실행에서 Agent 1의 새 논문 3편 검색·수집, Agent 2의 실제 저장 논문 참고문헌 집계, Agent 4의 실제 Groq 생성과 최대 한 번 Coverage 재작성을 확인했다. 이전 전체 보조 도구를 포함한 오프라인 테스트는 147개가 통과했다. 이번 범위 축소 후의 테스트 수는 별도로 기록한다.

이번 범위 축소 복사본에서 오프라인 테스트 **106개 통과, 실제 연동 2개 제외**를 확인했다. 서버 패키지 a2a/fastapi/uvicorn/starlette를 import할 수 없도록 제한한 상태에서 실행했다. 설치 잠금 파일의 필요한 전이 의존성 누락과 버전 충돌도 검사해 없음을 확인했다. 이전 147개에서 제외된 41개는 A2A/전달 도구/보조 GROBID 프로브 테스트이며 에이전트 테스트 실패로 줄어든 것이 아니다. 에이전트 내부 HTML/PDF·TEI 파싱 테스트는 유지한다.

외부 서비스 실제 연동을 이번 정리 작업에서 다시 실행하지는 않는다. Writer 예시는 실제 원문 발췌를 담은 시험 입력이며 빈 분석 필드를 임의로 채우지 않는다. 최종 사실 검증은 완료로 표시하지 않는다.

## 남은 담당 개발

논문별 Future Work 입력과 보고서 반영, 논문별 한계·공통 참고문헌 표시 강화가 남아 있다. Future Work는 논문 저자가 원문에서 제안한 향후 연구로 취급하며, 시스템이 도출한 Research Gaps와 구분한다. 필요한 원문 근거가 없으면 미기재로 표시한다. 공통 문헌은 선정 논문 중 최소 두 편이 실제 인용한 문헌만 포함한다.
